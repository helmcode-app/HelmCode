# File type icons (Devicon)

Brand icons under this asset group come from [Devicon](https://github.com/devicons/devicon)
(source SVG `*-original` preferred, then `*-plain`).

They are stored as **PNG at 1x / 2x / 3x** (24 / 48 / 72 px) so Asset Catalog
“Scales = Individual / All” works reliably on iPadOS (SVG single-scale assets
can fail or look wrong in some Xcode / runtime paths).

License: MIT — see https://github.com/devicons/devicon/blob/master/LICENSE

Only icons for languages/tools recognized by HelmCode’s `FileLanguageHint` are bundled.
